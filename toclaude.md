## Task 1: True Final-Frame Provenance

First deliverable: implement and test final-frame provenance in the Python
renderer:

```text
cranamp_cli/cranamp/tools/cranamp_cli.py
```

The current renderer has the right central hooks:

```text
Renderer.blit()
Renderer.composite_procedural()
Renderer.fill_rect()
Renderer.erase_rect_with_edge_average()
_render_window_pass()
render_with_params()
```

Add a final-frame provenance buffer:

```text
Renderer.provenance: np.ndarray uint32, shape [canvas_h, canvas_w]
0 = no clean source BMP pixel survives here
nonzero = encoded exported BMP pixel source
```

Use stable file ids from `TRAINABLE_EXPORT_SPECS` order:

```python
id = 1 + (file_id << 22) + (src_y << 11) + src_x
```

Decode:

```python
id0 = id - 1
src_x = id0 & 0x7FF
src_y = (id0 >> 11) & 0x7FF
file_id = id0 >> 22
```

Renderer rules:

```text
sprite blit:
  write provenance only where the rendered source pixel alpha contributes
  transparent/magenta pixels do not write provenance
  scaled blits map each destination pixel back to the source pixel used by
  the same nearest-neighbor rule as the render

procedural fills / erases / text / histograms:
  write RGB as before
  set provenance to 0 wherever the procedural content contributes

overdraw:
  later draws overwrite earlier provenance

window pass:
  sub-canvas rendering must also use a sub-provenance buffer
  when the window is stretched, resize provenance with nearest-neighbor
  when compositing the stretched window, copy provenance only where the
  stretched window alpha contributes; transparent window pixels must not
  clear previous final-frame provenance
```

This must be **final-frame** provenance. Pre-overdraw "source was blitted
somewhere" is not sufficient.

## Task 2: Provenance Unit Tests

Add tests before any ML code. Recommended file:

```text
tests/test_final_frame_provenance.py
```

Minimum tests:

```text
1. sprite identity:
   a visible MAIN.bmp source pixel writes the expected file_id/src_x/src_y.

2. transparent/magenta:
   transparent source pixels do not write provenance.

3. overdraw:
   draw MAIN, then draw CBUTTONS over it; covered MAIN pixels must no longer
   be labeled MAIN.

4. procedural clear/fill:
   fill_rect or erase_rect_with_edge_average over a previously sourced pixel
   sets provenance to 0.

5. text/procedural overlay:
   playlist text drawn by composite_procedural sets provenance to 0 where the
   text contributes.

6. scaled blit:
   scaled sprite provenance maps destination pixels back to valid source
   coordinates, matching the nearest-neighbor render rule.

7. window overdraw/stretch:
   _render_window_pass preserves provenance only for pixels with nonzero
   stretched window alpha and does not clear unrelated previous pixels.
```

If these tests fail, do not proceed to labels or V6.

## Task 3: V6 Labels

After provenance tests pass, generate per-sample V6 labels from synthetic
renders.

For every rendered sample, export:

```text
labels/{sample_id}.npz
```

For each trainable exported file:

```text
visible_mask: uint8 [H, W]
uv_target:    float16 or uint16 [2, H, W]
```

Source of truth:

```text
clean RGB target = clean exported BMP pixels / packed atlas crop
visible_mask / uv_target = final-frame provenance buffer
```

For each screen pixel:

```python
id = provenance_u32[screen_y, screen_x]
if id == 0:
    continue
file_id, src_x, src_y = decode(id)
visible_mask[file_id][src_y, src_x] = 1
uv_target[file_id][:, src_y, src_x] = normalized(screen_x, screen_y)
```

Use the same coordinate convention as the V6 `grid_sample` call. If
`align_corners=False` and the model input canvas is `INPUT_W x INPUT_H`, then:

```python
u = 2.0 * ((screen_x + 0.5) / INPUT_W) - 1.0
v = 2.0 * ((screen_y + 0.5) / INPUT_H) - 1.0
```

Store `uv_target` as `(u, v)`. During composition, permute model output from
`[B, 2, H, W]` to `[B, H, W, 2]` before calling `grid_sample`.

If multiple screen pixels map to the same source BMP pixel because of scaling:

```text
use a deterministic representative coordinate
do not average disconnected source locations
```

First coordinate is acceptable for the initial implementation. If you later
track alpha/coverage, choose highest contribution.

For full-scale later, sparse labels may be better:

```text
file_id uint8
src_x uint16
src_y uint16
screen_x uint16
screen_y uint16
```

But for one-skin / hard-skin probes, dense `.npz` arrays are fine.

## Task 4: V6 Model

Create:

```text
models/slotnet_v6.py
```

Keep the V5/exported-BMP contract:

```text
input image -> exact exported BMP tensors
TRAINABLE_EXPORT_SPECS
static support masks for final RGB loss/eval
same infer/export path eventually
```

Per file, output exact file dimensions:

```text
uv_grid          [B, 2, H, W]   normalized grid_sample coords
copy_conf_logits [B, 1, H, W]
copy_residual    [B, 3, H, W]
fallback_logits  [B, 3, H, W]
final_rgb        [B, 3, H, W]
```

Composition:

```python
copy_rgb = grid_sample(input_view, uv_grid.permute(0, 2, 3, 1), align_corners=False)
copy_refined = clamp(copy_rgb + residual_scale * tanh(copy_residual), 0, 1)
alpha = sigmoid(copy_conf_logits)
fallback_rgb = sigmoid(fallback_logits)
final_rgb = alpha * copy_refined + (1 - alpha) * fallback_rgb
```

Start:

```text
residual_scale = 0.20 or 0.25
query_grid_divisor = 4
base_channels = 24
style_dim = 192
attn_dim = 128
attention_heads = 4
```

Use the V5 encoder as a starting point, but do not rely only on generated
pixels. The direct `grid_sample(input_view, uv_grid)` path is the point of V6.

